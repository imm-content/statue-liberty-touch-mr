# 내 책상 위의 자유의 여신상 | 손가락 조작 MR

## 실행 주소
https://imm-content.github.io/statue-liberty-touch-mr/

## 파일 구성
- `index.html`: 실행 페이지
- `statue_of_liberty_1.glb`: 기존 3D 모델 (저장소에 있는 파일 유지)
- `README.md`: 사용 및 오류 해결 안내

## 실행 방법
1. WebXR immersive-ar 및 hit-test를 지원하는 Android 스마트폰의 Chrome에서 HTTPS 실행 주소를 엽니다.
2. 3D 모델을 확인하고 AR 시작 버튼을 누릅니다.
3. 필요한 카메라 권한을 허용하고 밝은 곳에서 책상이나 바닥을 천천히 비춥니다.
4. 녹색 원이 나타나면 화면을 한 번 터치하여 모형을 배치합니다.
5. DOM Overlay 지원 환경에서는 한 손가락으로 회전, 두 손가락으로 이동·확대·축소할 수 있습니다.
6. 재배치 버튼으로 새로운 위치를 선택합니다.

미지원 환경에서는 일반 3D 미리보기를 이용합니다. 후면 카메라가 작동하더라도 WebXR 표면 인식이 보장되지는 않습니다.

## 이번 보완 사항
- 녹색 원의 색상, 두께, 렌더링 우선순위 개선 및 프러스텀 컬링 해제
- Hit Test Source 초기화 실패 시 2초 간격으로 재시도
- 세션 종료 후 이전 비동기 요청 결과가 새 세션에 반영되지 않도록 보호
- 표면 인식 결과 건수 및 대기 시간 표시
- 15초 이상 표면 미인식 시 환경 개선 안내
- 유효한 위치 정보가 없으면 녹색 원 숨김
- 기존 GLB 경로, 화면 디자인, 손가락 조작 및 재배치 기능 유지

## 오류 해결
| 화면 상태 | 확인 사항 |
|---|---|
| AR 시작 버튼 없음 | Chrome, 기기 WebXR 지원 여부, Google Play AR 서비스 확인 |
| 초기화 실패 반복 | 표시된 오류 이름 확인, AR 세션 종료 후 재시작 |
| 표면 인식 0건 지속 | 밝은 조명, 무늬 있는 표면, 천천히 카메라 이동 |
| 결과 건수는 있으나 원 미표시 | 위치 정보 및 렌더링 상태 추가 확인 |
| 녹색 원 표시 후 배치 불가 | GLB 로딩 완료 여부 및 터치 입력 확인 |

## 검증 범위
원본 HTML을 기반으로 수정했습니다. 실제 Android 기기의 ARCore 공간 인식 및 배치 동작은 배포 후 확인해야 합니다. 녹색 원을 임의로 표시하는 대체 배치는 적용하지 않았습니다.
